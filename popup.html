Version 2.8.19. Civitai processing defaults to one request across all tabs. Open the cogwheel Settings panel to choose one to four, adjust automatic browsing and collection speed, or configure server transfers. Prompt records are sent in batches of up to 60 with a 3-second pause, with a shared 600-image queue. Server image downloads run separately. Use the panel to stop or resume this tab, and Browsing & activity for live queue updates.
